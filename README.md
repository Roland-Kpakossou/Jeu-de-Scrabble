# Scrabble Game

A Scrabble game I built during my university studies.  
2 to 4 players can play on a real graphical interface.


## What I learned

- Object-oriented programming (classes, inheritance, encapsulation)
- Building a GUI with Tkinter
- Handling errors with custom exceptions
- Writing unit tests with Pytest
- Working in a team using Git/GitHub


## Features

- Graphical board and racks
- Up to 4 players
- Word validation with a dictionary (French/English)
- Automatic score calculation
- Turn management


## How to run

python main.py

## Run tests

pytest tests/
